# Student Performance Prediction System

## Project Overview
This project uses Machine Learning to predict students' final academic grades based on their academic information.

## Objectives
- Analyze student academic performance.
- Train Machine Learning models.
- Compare Linear Regression and Random Forest.
- Predict final grades using student details.
- Provide an interactive web application.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Flask

## Machine Learning Models
1. Linear Regression
2. Random Forest Regressor

## Dataset
Student Performance Dataset (student-mat.csv).

## Application
The Flask application accepts student details and predicts the final grade out of 20.

## How to Run

Install dependencies:

    python -m pip install -r requirements.txt

Run the application:

    python app.py

Open:

    http://127.0.0.1:5000

## Conclusion
This project demonstrates how Machine Learning can help analyze and predict student academic performance.
